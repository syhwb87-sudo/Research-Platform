              성과 총액 — 유형별 산식과 대상 식별 Key

              성과 총액 = 유형별 산식 × ERP 스냅샷 변수. 역효과·기여율·직접비용을 반영하기 전 금액이며, 산식은 재무실이 버전으로 관리합니다 (연구원은 산식 작성자가 아니라 대상 Key 지정자). 행을 누르면 산식 구조·변수·Key 상세와 미리계산기가 열립니다.

              산식 미리계산기 검토용 · 등록값 아님

              변수 값을 넣으면 선택한 산식으로 성과 총액을 계산합니다. 등록 시에는 ERP 스냅샷 값이 자동 대입됩니다.

              유형별 등록 성과 총액

              등록 성과 기준 · 코드별 총액(억원)과 건수 — 등록이 없는 유형은 표시하지 않습니다

              대상 식별 Key 사전

                역효과(Erosion) 점검

                연구성과로 발생한 긍정적 효과뿐만 아니라 타 부문에서 연쇄적으로 발생할 수 있는 비용 증가, 업무부하 증가, 품질·납기 리스크 및 환경부하 등의 마이너스 효과를 함께 점검합니다.

                '해당' 판정은 연구성과가 무효라는 의미가 아닙니다. 성과 계산 및 검증 과정에서 추가 확인하거나 재무성과에서 조정해야 할 가능성이 있음을 의미합니다.

                점검 대상 · 적용 재무성과 코드

                대상 성과를 고르면 등록 유형이 기본 적용되며, 코드를 추가 선택하면 해당 그룹의 유형별 체크리스트가 합산됩니다 (중복 항목은 한 번만 표시)

                역효과 점검 체크리스트

                공통 8개 항목은 항상 표시되고, 선택한 재무성과 코드의 그룹(A·B·C)에 따라 유형별 추가 항목이 더해집니다 — 판정: ⚠ 해당 · ✓ 해당없음 · ? 판단불가

                공통 체크리스트

                유형별 추가 체크리스트

                역효과 조정 검토 요약 검토용 · 자동 차감 아님

                '해당' 판정 항목 기준. 단위가 다른 금액은 합산하지 않고 단위별로 표시하며, '판단불가' 항목은 합계에서 제외하고 추가 확인 대상으로 집계합니다

                역효과 대표 카탈로그

                재무성과 코드별로 자주 발생할 수 있는 대표 역효과와 권장 산정방식을 제공합니다. 카탈로그는 자동 차감 기준이 아니라, 연구성과 검증 시 확인해야 할 대표 사례입니다.
                권장 산정의 금액은 검토 참고값이며 최종 재무성과에서 자동 차감되지 않습니다. 카탈로그가 없는 코드는 같은 그룹의 일반 점검 사례로 대체 표시됩니다.

                연구 기여율 산정 — 유형별 표준 기여율 테이블 v1 (재무실 고시)

                연구성과 유형을 고르면 표준 기여율이 기본값으로 적용됩니다. 연구 외 요인이 크면 하향, 연구기술이 성과의 직접 원인임을 입증하면 상향을 선택할 수 있으며, 각 조건은 참고 문구가 아니라 기여율 변경의 판단 기준입니다.

                표준 적용 기본값유형별 표준 기여율을 그대로 적용합니다. 별도 판단·승인이 필요 없습니다.
                하향 적용 활용부서장 판단연구 외 요인의 영향이 크거나 연구의 직접 기여도가 표준보다 낮은 경우. 판단 사유와 근거를 기록합니다.
                상향 적용 재무실 승인연구결과·연구기술이 성과 발생의 직접 원인임을 입증한 경우. 승인 전까지는 표준 기여율이 유효합니다.
